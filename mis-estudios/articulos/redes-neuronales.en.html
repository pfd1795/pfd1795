Neural networks

A neural network is a machine learning model made of connected units that combine inputs with weights and apply activation functions. In this article you will see how a neuron works, how they are organized into layers, how the network learns through backpropagation, and what to keep in mind to train it well.

In 5 points

  • A neural network is a model made of units (artificial neurons) organized into layers that transform data.
  • Each neuron computes a weighted sum of its inputs, adds a bias and applies an activation function.
  • Information flows from the input layer to the output layer in the forward pass.
  • Training adjusts weights and biases with backpropagation and gradient descent, measuring error with a loss function.
  • Deep learning uses networks with many layers; more layers do not guarantee better results.

What is a neural network?

A neural network is a mathematical model made of computing units called artificial neurons, connected to each other and organized into layers. Each connection has an adjustable weight, and training consists of modifying those weights so that the network produces useful outputs from inputs.

Neural networks are a family of models within machine learning. When a network has many hidden layers, it is called deep learning, which is the basis of many current applications in image recognition, speech and text generation.

The name and the usual drawing —connected units— recall biological neurons, but the analogy is very limited: an artificial neuron is simply a function that sums, scales and transforms numbers.

Key idea: a neural network does not «think» and does not work like a brain. It is a mathematical model with parameters adjusted from data.

Key concepts

  • Artificial neuron: unit that computes a weighted sum of its inputs, adds a bias and applies an activation function.
  • Weight: parameter that multiplies an input; it indicates how much influence that input has on the neuron.
  • Bias: constant value added to the weighted combination that shifts the neuron's output.
  • Activation function: non-linear function applied to the neuron's output, such as sigmoid, tanh or ReLU.
  • Layer: set of neurons that receive the same inputs. The input layer, hidden layers and output layer are distinguished.
  • Deep network: network with several hidden layers between input and output.
  • Forward pass: flow of computation from input to output, layer by layer.
  • Loss function: measure of the error between the network's output and the expected value; training seeks to reduce it.
  • Backpropagation: algorithm that computes how much each weight contributes to the error, applying the chain rule from back to front.
  • Gradient descent: optimization method that updates parameters in the direction that reduces the loss.
  • Learning rate: size of the step with which parameters are updated in each iteration.
  • Epoch and batch: an epoch is a full pass through the training data; a batch is the subset of examples used in each update.

How a network works

The neuron: weighted sum and activation

Each neuron receives input values x1, x2, …, xn, multiplies them by its weights and adds a bias: z = w1·x1 + w2·x2 + … + wn·xn + b. It then applies an activation function f(z), whose non-linearity lets the network represent relationships that are neither proportional nor additive. Without non-linear activation, stacking layers would be equivalent to a single linear transformation.

Two common activations to start with are the sigmoid, which compresses any value into the interval (0, 1) and is used in binary outputs, and ReLU (rectified linear unit), which returns zero for negative values and the value itself for positive ones, and is the most common choice in hidden layers.

From input layer to output layer

Neurons are grouped into layers: the input layer receives the example's features, one or several hidden layers transform that information and the output layer produces the prediction. Each layer connects to the next through weights, and each connection represents an adjustable parameter during training.

In recognition tasks, the first layers tend to represent simple patterns and later layers combine those patterns into more abstract representations. What exactly each layer represents depends on the data and the task, and is not fixed in advance.

Without non-linear activation functions between layers, the whole network reduces to a single linear transformation, no matter how many layers it has: depth would lose all its effect.

How it learns: loss and backpropagation

At the start of training, weights are initialized with small random values and the network produces barely useful outputs. Learning consists of repeating a correction cycle until the loss function is low enough on data the network did not see during adjustment.

  1. Initialize: assign initial values to weights and biases.
  2. Forward pass: compute the network's prediction for a batch of examples.
  3. Measure the loss: compare the prediction with the expected values.
  4. Backpropagate: compute the gradient of the loss with respect to each weight, propagating the error from back to front.
  5. Update: move each parameter against its gradient, scaled by the learning rate.
  6. Repeat: go through the data in batches over several epochs, watching behavior on evaluation data.

Backpropagation is not a separate learning method, but the efficient way of applying the chain rule to obtain the gradient of each parameter in networks with many layers. With those gradients, gradient descent updates parameters just like in any machine learning model.

The learning rate is delicate: a value too large makes the loss oscillate or grow, and one too small makes training extremely slow. It is worth trying values in powers of ten and observing the loss curve.

Common architectures

The way layers are connected defines the network's architecture. The choice depends on the type of data and the task: the same structure should not be used for a table, an image or a text sequence.

Architecture Core idea Typical uses
Multilayer perceptron (MLP) Dense layers: each neuron connects to all of those in the previous layer. Tabular data, basic classification and regression.
Convolutional networks (CNN) Filters that slide over the data sharing weights and detect local patterns. Images and signals with spatial structure.
Recurrent networks (RNN, LSTM) They keep a state that updates step by step along the sequence. Time series, text, audio.
Transformers Attention mechanism that relates all positions of the input to each other. Language models, translation, content generation.

Architectures do not replace the training process: all of them are adjusted with forward passes, loss, backpropagation and gradient descent. What changes is how connections are organized and which assumptions are built in about the data.

Illustrative examples

These examples use basic Python, without machine learning libraries, to show the underlying computation. In real projects, libraries such as PyTorch or TensorFlow are used, which compute gradients automatically.

A neuron: weighted sum, bias and activation

A neuron's computation reduces to three operations: multiplying inputs by weights, adding the bias and applying the activation. 

import math

# A neuron: weighted sum + bias + activation.
inputs = [0.5, 1.0, 2.0]
weights = [0.4, -0.2, 0.1]
bias = 0.05

z = sum(x * w for x, w in zip(inputs, weights)) + bias
# z = 0.2 - 0.2 + 0.2 + 0.05 = 0.25

def sigmoid(z):
    return 1 / (1 + math.exp(-z))

def relu(z):
    return max(0.0, z)

print(z)             # 0.25
print(sigmoid(z))   # ≈ 0.562
print(relu(z))       # 0.25

Forward pass in a small network

A complete network chains that computation by layers: the output of each layer becomes the input of the next. 

# Minimal network: 2 inputs → hidden layer (2 neurons with ReLU) → output with sigmoid.
import math

def sigmoid(z):
    return 1 / (1 + math.exp(-z))

def relu(z):
    return max(0.0, z)

inputs = [1.0, 2.0]

# Each hidden neuron is described by its weights and bias: [w1, w2, b].
hidden_layer = [
    [0.5, -0.1, 0.2],   # neuron 1
    [0.2, 0.4, -0.1],   # neuron 2
]

hidden = []
for w1, w2, b in hidden_layer:
    z = inputs[0] * w1 + inputs[1] * w2 + b
    hidden.append(relu(z))

# The output neuron combines the hidden activations.
output_weights = [0.7, 0.6]
output_bias = -0.2
z_output = sum(h * w for h, w in zip(hidden, output_weights)) + output_bias
output = sigmoid(z_output)

print(hidden)   # [0.5, 0.9]
print(output)    # ≈ 0.666

The idea of training: lowering the loss by adjusting weights

Backpropagation computes gradients in large networks; in a single-weight model it can be done by hand. The example shows how gradient descent brings the weight closer to the ideal value step by step. 

# Minimal model: y = w * x. If the input is x=2, the desired output is 10.
# The ideal weight value is 5.0. We start from an arbitrary value.
x, y = 2.0, 10.0
w = 0.0        # initial weight value
rate = 0.1     # learning rate

for step in range(3):
    prediction = w * x
    error = prediction - y
    loss = error ** 2
    gradient = 2 * error * x        # derivative of the loss with respect to w
    w = w - rate * gradient         # move against the gradient
    print(f"step {step}: loss {loss:.2f}, w {w:.2f}")

# With more steps, w approaches the ideal value 5.0.

In a real network there are thousands or millions of weights, and backpropagation obtains all gradients in one backward pass reusing intermediate computations from the forward pass. The idea, however, is exactly that of this example.

Best practices

  • Start with small networks and a simple baseline before increasing layers or neurons.
  • Scale the inputs so they have comparable ranges or distributions.
  • Use a non-linear activation in hidden layers; ReLU is a common starting point.
  • Set aside evaluation data that does not take part in training and do not tune with it.
  • Watch the training and evaluation loss curves to detect overfitting in time.
  • Try the learning rate in powers of ten instead of tuning it blindly.
  • Fix random seeds and record the configuration to reproduce results.
  • In real projects, use maintained libraries instead of implementing backpropagation by hand.

Common mistakes

Mistake Why it is a problem What to do
Taking the brain analogy literally Leads to unrealistic expectations about how the network works and what it understands. Understand it as a mathematical model with adjustable parameters.
Omitting non-linear activation The whole network reduces to a linear transformation, even with many layers. Apply a non-linear activation in hidden layers.
Not scaling the inputs Very different magnitudes slow down or destabilize gradient descent. Normalize or standardize features before training.
Using an inadequate learning rate Too large: the loss does not converge. Too small: training takes far too long. Try powers of ten and observe the loss curve.
Using a huge network with little data The network memorizes the examples and generalizes poorly. Start small, regularize and get more data if possible.
Judging only by training loss May hide that the network does not generalize to new examples. Measure on held-out data and analyze concrete errors.

Quick reference

Term Meaning
neuron Unit that computes a weighted sum of its inputs, adds a bias and applies an activation.
weight Parameter that multiplies an input and is adjusted during training.
bias Constant added to the weighted combination that shifts the output.
activation function Non-linearity applied to a neuron's output, such as ReLU or sigmoid.
hidden layer Intermediate layer between input and output that transforms representations.
forward pass Computation of the network's output from an input, layer by layer.
backpropagation Algorithm that computes the gradient of the loss with respect to each parameter.
gradient descent Update of parameters against their gradient to reduce the loss.
learning rate Size of the step of each parameter update.
epoch One full pass through the training data.
