Fundamentos de computación

Inteligencia artificial

La inteligencia artificial (IA) reúne métodos que permiten a los sistemas informáticos realizar tareas que suelen requerir capacidades asociadas con la inteligencia humana. En este artículo conocerás sus conceptos fundamentales, cómo aprende un modelo y qué límites conviene tener presentes al usarlo.

En 5 puntos

  • La IA es un campo amplio; el aprendizaje automático es una de sus áreas.
  • Un modelo aprende patrones a partir de datos y los utiliza para producir resultados.
  • Entrenar un modelo y usarlo para inferir son etapas distintas.
  • La calidad de los datos y la evaluación influyen en la utilidad del sistema.
  • Las salidas de IA pueden ser inexactas, sesgadas o inadecuadas para el contexto.

¿Qué es la inteligencia artificial?

La inteligencia artificial es el área de la informática que estudia y construye sistemas capaces de realizar tareas como clasificar información, reconocer patrones, generar contenido, recomendar opciones o planificar acciones. No existe una única técnica de IA: el campo incluye métodos basados en reglas, búsqueda, optimización y aprendizaje a partir de datos.

Un sistema de IA no necesariamente piensa o comprende como una persona. En muchos casos, calcula una salida a partir de una entrada y de patrones que se han definido manualmente o aprendido durante el entrenamiento.

Idea clave: que un sistema produzca una respuesta convincente no demuestra, por sí solo, que esa respuesta sea correcta ni que el sistema comprenda el tema.

Conceptos clave

  • Aprendizaje automático: conjunto de métodos que permiten a un sistema ajustar un modelo usando datos, en lugar de especificar manualmente todas las reglas.
  • Aprendizaje supervisado: entrenamiento con ejemplos que incluyen entradas y respuestas esperadas, como imágenes etiquetadas por categoría.
  • Aprendizaje no supervisado: búsqueda de estructuras o grupos en datos sin etiquetas de respuesta proporcionadas de antemano.
  • Aprendizaje por refuerzo: aprendizaje mediante interacciones y señales de recompensa o penalización.
  • Modelo: representación matemática ajustada para producir resultados a partir de entradas.
  • Entrenamiento: proceso de ajustar los parámetros del modelo con datos.
  • Inferencia: uso de un modelo ya entrenado para producir una predicción o respuesta.
  • Red neuronal: familia de modelos compuestos por unidades conectadas que transforman datos mediante capas de operaciones.
  • Aprendizaje profundo: área del aprendizaje automático que emplea redes neuronales con múltiples capas.
  • Datos de entrenamiento: ejemplos utilizados para ajustar el modelo; su cobertura y calidad afectan lo que el modelo puede aprender.

La IA generativa es una categoría de sistemas que producen contenido —por ejemplo, texto, imágenes o audio— a partir de patrones aprendidos. Su salida puede ser útil, pero debe comprobarse según el uso previsto.

Cómo funciona un sistema de IA

En un sistema de aprendizaje automático típico, los datos se preparan y se utilizan para ajustar un modelo. Después, el modelo se evalúa con ejemplos que no se usaron para entrenarlo. Si su desempeño es adecuado para la tarea, puede utilizarse para inferir resultados sobre entradas nuevas.

  1. Definir la tarea: especificar qué entrada recibe el sistema y qué resultado se espera.
  2. Preparar los datos: revisar, organizar y, cuando corresponda, etiquetar los ejemplos.
  3. Entrenar: ajustar el modelo para que encuentre patrones útiles en los datos.
  4. Evaluar: medir su comportamiento en datos separados y analizar sus errores.
  5. Usar y supervisar: aplicar el modelo en un contexto definido y revisar si sigue siendo apropiado.

Un buen resultado en los datos de entrenamiento no garantiza que el modelo funcione bien con ejemplos nuevos. También es importante comprobar si los datos de evaluación representan el contexto real de uso.

Ejemplos ilustrativos

Clasificación con reglas sencillas

Este ejemplo no entrena un modelo: usa una regla escrita por una persona para clasificar una señal numérica. Sirve para contrastar una solución basada en reglas con una que aprende patrones a partir de datos. 

def clasificar_temperatura(celsius):
    if celsius < 10:
        return "fría"
    if celsius < 25:
        return "templada"
    return "cálida"

print(clasificar_temperatura(18))  # templada

Separar datos para evaluar un modelo

El siguiente fragmento muestra la idea de separar los ejemplos antes de evaluar. Es ilustrativo: no implementa entrenamiento ni depende de una biblioteca de aprendizaje automático. 

datos = [
    {"entrada": "ejemplo 1", "etiqueta": "A"},
    {"entrada": "ejemplo 2", "etiqueta": "B"},
    {"entrada": "ejemplo 3", "etiqueta": "A"},
    {"entrada": "ejemplo 4", "etiqueta": "B"},
]

# En un proyecto real, la separación suele hacerse de forma reproducible
# y teniendo en cuenta el tamaño y la distribución de los datos.
datos_entrenamiento = datos[:3]
datos_evaluacion = datos[3:]

print("Entrenamiento:", len(datos_entrenamiento))
print("Evaluación:", len(datos_evaluacion))

Estos ejemplos usan Python básico para explicar ideas. No son un modelo de IA listo para producción ni miden la calidad de una predicción.

Aplicaciones y límites

Las técnicas de IA se utilizan en tareas diversas, como filtrar correo no deseado, reconocer objetos en imágenes, recomendar contenidos, transcribir voz o ayudar a explorar grandes conjuntos de datos. La conveniencia de cada método depende de la tarea, los datos disponibles y el impacto de los errores.

Entre sus límites se encuentran la dependencia de los datos, la dificultad para explicar algunas decisiones, el posible sesgo, la variación en la calidad de las salidas y la falta de garantía de que un sistema generativo proporcione información verdadera.

En decisiones de alto impacto —por ejemplo, relacionadas con salud, empleo, crédito o acceso a servicios— no conviene tratar la salida del modelo como una decisión final sin controles, evaluación y supervisión adecuados.

Buenas prácticas

  • Definir con claridad la tarea y las condiciones en las que se utilizará el sistema.
  • Comprobar que los datos sean pertinentes, suficientemente representativos y obtenidos de forma apropiada.
  • Separar los datos de evaluación de los usados para entrenar el modelo.
  • Medir más de un aspecto del desempeño cuando una sola métrica pueda ocultar errores importantes.
  • Revisar ejemplos incorrectos y analizar a quiénes afectan esos errores.
  • Proteger los datos personales y limitar su uso a lo necesario.
  • Informar cuándo una salida fue generada o asistida por IA, si el contexto lo requiere.
  • Mantener supervisión humana cuando el impacto de una salida sea significativo.
  • Volver a evaluar el sistema si cambian los datos, el contexto o los objetivos.

Errores comunes

Error Por qué es un problema Qué hacer
Confundir IA con aprendizaje automático El aprendizaje automático es una parte del campo, no un sinónimo de toda la IA. Identificar qué técnica concreta realiza la tarea.
Suponer que una respuesta fluida es verdadera La forma de expresarse no garantiza exactitud ni comprensión. Verificar los datos importantes con fuentes apropiadas.
Evaluar solo con datos de entrenamiento Puede ocultar que el modelo no generaliza a ejemplos nuevos. Usar datos separados para evaluar y analizar los errores.
Ignorar la calidad y procedencia de los datos Los problemas en los datos pueden reflejarse en las predicciones. Documentar, revisar y proteger los datos utilizados.
Automatizar una decisión sin supervisión Los errores pueden tener consecuencias desproporcionadas. Establecer controles acordes con el riesgo de la tarea.
