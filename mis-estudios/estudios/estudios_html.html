Web (HTML, CSS y JavaScript)

HTML

HTML (HyperText Markup Language) es el lenguaje de marcado que describe la estructura y el significado del contenido de una página web. El navegador lo lee y construye el DOM, el árbol de nodos sobre el que trabajan CSS y JavaScript.

¿Qué es y cómo funciona?

HTML no es un lenguaje de programación: no tiene variables, condiciones ni bucles. Es un lenguaje de marcado compuesto por elementos, que se escriben con una etiqueta de apertura, contenido y una etiqueta de cierre: <p>texto</p>. Algunos elementos no necesitan cierre, como <img> o <br>.

El navegador lee el HTML de arriba abajo y construye el DOM (Document Object Model). La apariencia la define CSS y el comportamiento dinámico, JavaScript.

Regla de oro: el HTML describe qué es cada cosa (un título, un párrafo, una cita), no cómo se ve. De cómo se ve se encarga CSS.

Estructura mínima de un documento

<!DOCTYPE html>
  <html lang="es">
    <head>
      <meta charset="utf-8">
      <meta name="viewport" content="width=device-width, initial-scale=1">
      <title>Mi página</title>
    </head>
    <body>
      <h1>Hola</h1>
      <p>Primer párrafo.</p>
    </body>
  </html>
  • <!DOCTYPE html> activa el modo estándar del navegador. No lo omitas.
  • lang="es" indica el idioma: lo usan lectores de pantalla y traductores.
  • charset="utf-8" es imprescindible para tildes y eñes correctas.
  • viewport hace que la página se adapte a pantallas de móvil.
  • El <head> contiene metadatos; el <body>, lo visible.

Etiquetas y semántica

Usar la etiqueta adecuada mejora la accesibilidad, el SEO y el mantenimiento. Los landmarks dividen la página en zonas reconocibles: 

<body>
    <header>Cabecera del sitio</header>
    <nav>Enlaces de navegación</nav>
    <main>
      <article>
        <h2>Título del artículo</h2>
        <p>Contenido principal...</p>
      </article>
      <aside>Información relacionada</aside>
    </main>
    <footer>Pie de página</footer>
  </body>

Para el texto y los enlaces:

<p>
    Texto con <strong>importancia</strong>, <em>énfasis</em> y
    un <a href="estudios_css.html">enlace a CSS</a>.
  </p>
  <ul>
    <li>Elemento de lista no ordenada</li>
  </ul>
  <blockquote cite="https://example.org">Cita textual.</blockquote>
  <pre><code>código preformateado</code></pre>

La jerarquía de encabezados <h1> a <h6> debe ser coherente: normalmente un solo <h1> por página y sin saltar niveles.

Formularios y accesibilidad

Cada campo debe tener su <label> asociado mediante for e id: al pulsar la etiqueta se enfoca el campo y los lectores de pantalla lo anuncian correctamente. 

<form action="/enviar" method="post">
    <label for="correo">Correo electrónico</label>
    <input type="email" id="correo" name="correo" required autocomplete="email">

    <fieldset>
      <legend>Preferencias</legend>
      <label>
        <input type="checkbox" name="avisos">
        Recibir avisos
      </label>
    </fieldset>

    <button type="submit">Enviar</button>
  </form>
  • Usa el type adecuado (email, number, date, search…): el navegador valida y muestra teclados adaptados.
  • required obliga a rellenar; autocomplete ayuda a autorrellenar.
  • fieldset y legend agrupan campos relacionados.
  • button type="submit" envía el formulario; type="button" no.

Accesibilidad mínima: texto alt en las imágenes, contraste suficiente, navegación con teclado y estructura de encabezados ordenada.

Buenas prácticas

  • Elige el elemento por su significado, no por su aspecto. Un botón es <button>, no un <div> con un clic.
  • Indenta de forma consistente (dos espacios) y escribe etiquetas y atributos en minúsculas.
  • Cierra siempre las comillas de los atributos y todos los elementos que lo requieran.
  • Todo <img> necesita alt; si es decorativa, déjalo vacío: alt="".
  • Valida el documento para detectar anidamientos incorrectos.
  • No uses <br> ni tablas para maquetar: eso es trabajo de CSS.

Errores comunes

Error Por qué está mal Qué hacer
Olvidar charset="utf-8" Las tildes y símbolos se ven como caracteres extraños. Añadirlo como primer elemento del <head>.
Varios <h1> y niveles saltados Confunde a lectores de pantalla y al SEO. Un <h1> por página y jerarquía continua.
Anidar <p> dentro de <p> El navegador cierra el párrafo antes de tiempo y reordena el DOM. Usa elementos válidos para agrupar, como <div>.
Estilos con el atributo style="" Mezcla contenido y presentación y es difícil de mantener. Defínelos en CSS con clases semánticas.
Tablas para distribuir el diseño Rompe la semántica y la adaptación a móvil. Usa Flexbox o Grid; reserva las tablas para datos tabulares.
