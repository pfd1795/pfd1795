Lenguajes de programación

Python

Python es un lenguaje de alto nivel, interpretado y multiparadigma, famoso por su sintaxis legible y su enorme ecosistema. Se usa en scripting, automatización, ciencia de datos, machine learning, backend web y herramientas de sistema. Su filosofía («The Zen of Python») prioriza la legibilidad sobre la cleverness.

En 5 puntos

  • Python es interpretado y de tipado dinámico; no se compila a binario nativo (CPython bytecode).
  • La indentación es parte de la sintaxis: define bloques en lugar de llaves.
  • Sus estructuras de datos (listas, tuplas, dicts, sets) están en la biblioteca estándar y son muy expresivas.
  • El ecosistema se gestiona con pip y entornos virtuales (venv).
  • Es multiparadigma: soporta imperativo, OOP y funcional; brilla en scripting y datos.

¿Qué es Python y cuándo usarlo?

Creado por Guido van Rossum (1991), Python prioriza la productividad del desarrollador. Casos típicos:

  • Scripting y automatización: tareas del sistema, ETL, scraping.
  • Ciencia de datos / ML: NumPy, pandas, scikit-learn, PyTorch.
  • Backend web: Django, FastAPI, Flask.
  • Herramientas CLI y bots.

Python no es el más rápido en ejecución pura. Si el cuello de botella es CPU, se recurre a C/C++/Rust (extensiones), PyPy, o a paralelismo con multiprocessing.

Sintaxis básica

# Comentario de línea
"""Docstring de varias líneas."""

x = 10          # int
y = 3.14        # float
nombre = "Ana"  # str
activo = True   # bool (mayúscula)

# Control de flujo
if x > 5:
    print("grande")
elif x == 5:
    print("igual")
else:
    print("pequeño")

# Bucles
for i in range(5):
    print(i)

while x > 0:
    x -= 1

# Función
def saludar(nombre: str) -> str:
    return f"Hola, {nombre}"

La indentación (convención: 4 espacios) define bloques; mezclar espacios y tabuladores da error. Las f-strings (f"...") permiten interpolar expresiones.

Estructuras de datos

# Lista (mutable, ordenada)
frutas = ["manzana", "pera"]
frutas.append("uva")
frutas[0]            # "manzana"

# Tupla (inmutable)
punto = (3, 4)

# Diccionario (clave-valor)
usuario = {"nombre": "Ana", "edad": 30}
usuario["email"] = "ana@mail.com"
usuario.get("tel", "n/a")

# Conjunto (sin duplicados)
tags = {"js", "python", "js"}  # {"js", "python"}

# Comprensiones
cuadrados = [n*n for n in range(5)]          # [0,1,4,9,16]
pares = {n for n in range(10) if n % 2 == 0}

Las comprensiones son la forma «pythónica» de transformar colecciones; preferibles a bucles explícitos cuando la lógica es simple. Para transformaciones complejas, usa bucles con nombres claros.

Funciones y módulos

def sumar(a: int, b: int) -> int:
    """Devuelve la suma de a y b."""
    return a + b

# Argumentos con valor por defecto y *args/**kwargs
def registrar(nombre, *, rol="user", **extra):
    print(nombre, rol, extra)

# Funciones de orden superior
def aplicar(fn, valor):
    return fn(valor)

# Módulos: importar desde la biblioteca estándar
import os
from pathlib import Path
from collections import Counter

# Crear un paquete propio: carpeta con __init__.py

Las funciones son objetos de primera clase: se pueden pasar como argumentos, guardar en variables y devolver. Eso habilita el estilo funcional (map/filter/reduce vía functools).

Entorno y dependencias

# Crear y activar un entorno virtual
python -m venv .venv
source .venv/bin/activate   # Linux/macOS
.venv\Scripts\activate      # Windows

# Instalar dependencias
pip install requests

# Fijar dependencias
pip freeze > requirements.txt
pip install -r requirements.txt

Nunca instales dependencias en el Python del sistema para un proyecto; usa siempre un entorno virtual. Para proyectos modernos, considera pyproject.toml y herramientas como uv o poetry.

Estilo y tipado

  • PEP 8: 4 espacios, nombres snake_case, clases PascalCase.
  • Anotaciones de tipo (PEP 484): opcionales en runtime, útiles con mypy/pyright.
  • Docstrings (PEP 257): documenta módulos, clases y funciones.
  • Formateadores: black, ruff.
from typing import List, Optional

def buscar(items: List[str], clave: str) -> Optional[int]:
    """Devuelve el índice de clave o None si no existe."""
    try:
        return items.index(clave)
    except ValueError:
        return None

Buenas prácticas

  • Usa entornos virtuales por proyecto.
  • Escribe funciones pequeñas con un solo propósito.
  • Prefiere comprensiones simples; bucles explícitos si la lógica es compleja.
  • Maneja errores con try/except específicos, no except: a secas.
  • Tipa el código público y valídalo con un checker.
  • Lee y sigue PEP 8; automatiza con formateadores.

Errores comunes

Error Por qué está mal Qué hacer
Argumento mutable por defecto (def f(x=[])) La lista se comparte entre llamadas. Usa None y crea la lista dentro.
Comparar con == None Funciona pero no es idiomático ni seguro con __eq__. Usa is None.
Modificar una lista mientras se itera Salta elementos o lanza errores. Itera sobre una copia o construye una nueva lista.
Olvidar activar el entorno virtual Se instala en el Python del sistema; conflictos. Verifica which python antes de instalar.
Usar except: a secas Oculta errores (incluido Ctrl+C). Captura excepciones específicas.
