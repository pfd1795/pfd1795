Aprendizaje automático

El aprendizaje automático es el área de la inteligencia artificial que permite a un sistema ajustar un modelo a partir de datos, en lugar de programar todas las reglas a mano. En este artículo verás qué es, qué tipos de aprendizaje existen, cómo se entrena y evalúa un modelo y qué errores conviene evitar al aplicarlo.

En 5 puntos

  • En lugar de escribir reglas manualmente, se proporcionan ejemplos y el sistema ajusta un modelo.
  • El aprendizaje supervisado usa ejemplos etiquetados; el no supervisado busca estructura; el por refuerzo aprende por prueba y error.
  • Entrenar y evaluar son etapas distintas: la evaluación necesita datos que el modelo no vio.
  • Un modelo que memoriza los datos de entrenamiento (sobreajuste) falla con ejemplos nuevos.
  • La utilidad de un modelo depende de los datos, de la métrica elegida y del contexto de uso.

¿Qué es el aprendizaje automático?

El aprendizaje automático (machine learning) es un conjunto de técnicas que permiten a un sistema mejorar su comportamiento en una tarea a partir de datos, sin que una persona especifique cada regla. En la programación clásica, la persona escribe las reglas y el programa las aplica a los datos; en el aprendizaje automático, se proporcionan datos con ejemplos y el proceso de entrenamiento produce el modelo que resuelve la tarea.

Es una de las áreas dentro de la inteligencia artificial, y hoy es la base de aplicaciones como filtros de correo no deseado, recomendadores, reconocimiento de voz y sistemas generativos. No todo sistema de IA usa aprendizaje automático: existen métodos basados en reglas o búsqueda que no aprenden de datos.

Idea clave: en programación clásica se escriben reglas que transforman datos en respuestas; en aprendizaje automático, los datos y las respuestas se usan para obtener las reglas (el modelo).

Conceptos clave

  • Ejemplo o instancia: un caso concreto de la tarea, por ejemplo una imagen o una fila de una tabla.
  • Característica (feature): cada propiedad medible de un ejemplo, como el tamaño de una casa o la antigüedad de un usuario.
  • Etiqueta: la respuesta esperada para un ejemplo en tareas supervisadas, como la categoría de una imagen.
  • Modelo: representación matemática que transforma entradas en salidas y que se ajusta durante el entrenamiento.
  • Parámetros: valores internos del modelo que el entrenamiento modifica, como los pesos de una recta o de una red neuronal.
  • Hiperparámetros: valores que la persona configura antes de entrenar, como el número de vecinos o la tasa de aprendizaje.
  • Función de pérdida o coste: medida del error entre lo que el modelo predice y lo esperado; el entrenamiento busca minimizarla.
  • Optimización: proceso de ajustar los parámetros para reducir la pérdida, por ejemplo mediante descenso de gradiente.
  • Conjuntos de datos: particiones de los ejemplos para entrenar, validar y evaluar el modelo.
  • Inferencia: uso del modelo ya entrenado para producir salidas sobre entradas nuevas.
  • Generalización: capacidad del modelo de funcionar bien con datos que no formaron parte del entrenamiento.

Tipos de aprendizaje

Aprendizaje supervisado

Se entrena con ejemplos que incluyen la etiqueta correcta. Si la etiqueta es una categoría, la tarea es clasificación (por ejemplo, decidir si un correo es o no spam); si es un valor numérico, la tarea es regresión (por ejemplo, estimar un precio).

Aprendizaje no supervisado

Los ejemplos no tienen etiquetas y el objetivo es descubrir estructura: agrupar casos similares (clustering), reducir la cantidad de dimensiones manteniendo lo importante, o encontrar reglas de asociación entre elementos.

Aprendizaje por refuerzo

Un agente toma decisiones en un entorno y aprende a partir de recompensas o penalizaciones, sin ejemplos etiquetados. Se usa en tareas secuenciales como el control de procesos o los juegos.

Tipo Qué recibe Qué produce Tareas típicas
Supervisado Ejemplos con etiquetas Modelo que predice la etiqueta Clasificar imágenes, estimar precios
No supervisado Ejemplos sin etiquetas Estructura: grupos, dimensiones, asociaciones Segmentar clientes, comprimir datos
Por refuerzo Interacciones con un entorno Política de decisiones Juegos, control, robótica

Cómo se entrena un modelo

En un flujo típico de aprendizaje supervisado, el entrenamiento consiste en ajustar los parámetros del modelo para que sus predicciones se acerquen a las etiquetas de los ejemplos. El proceso suele seguir estos pasos:

  1. Definir la tarea: precisar qué entrada recibe el sistema, qué salida se espera y cómo se medirá el éxito.
  2. Reunir y preparar los datos: seleccionar características, revisar errores y valores ausentes.
  3. Separar los datos: reservar ejemplos para evaluación que el modelo no usará durante el entrenamiento.
  4. Entrenar: ajustar los parámetros minimizando la función de pérdida sobre los datos de entrenamiento.
  5. Evaluar: medir el comportamiento con los datos reservados y analizar los errores.
  6. Usar y supervisar: aplicar el modelo en su contexto y vigilar que siga siendo adecuado.

Toda información del futuro que se cuele en el entrenamiento invalida la evaluación: es la fuga de datos (data leakage). Por ejemplo, usar para predecir ventas de un mes variables que solo se conocen después de cerrar el mes.

Generalización y sobreajuste

El objetivo no es acertar en los datos de entrenamiento, sino generalizar a ejemplos nuevos. Cuando un modelo se ajusta tan bien a los ejemplos de entrenamiento que memoriza sus particularidades, sufre sobreajuste (overfitting): su rendimiento en datos nuevos empeora. En el extremo opuesto, un modelo demasiado simple sufre subajuste: ni siquiera describe bien los datos de entrenamiento.

Para detectarlo se comparan las métricas en entrenamiento y en evaluación: una gran diferencia suele indicar sobreajuste. Técnicas habituales para mitigarlo incluyen usar más datos, simplificar el modelo o aplicar regularización.

Regla de oro: nunca evalúes un modelo con los mismos datos con los que se entrenó, y no ajustes hiperparámetros usando el conjunto de prueba.

Ejemplos ilustrativos

Estos ejemplos usan Python básico, sin bibliotecas de aprendizaje automático, para mostrar las ideas de fondo. En proyectos reales se emplean bibliotecas como scikit-learn.

Entrenar es ajustar parámetros: una recta por mínimos cuadrados

El ejemplo más simple de modelo con parámetros es una recta y = pendiente·x + origen. «Entrenar» consiste en calcular los dos parámetros que minimizan el error cuadrático frente a los ejemplos. 

# Ajusta una recta y = pendiente * x + origen a los ejemplos
# (mínimos cuadrados). "Entrenar" aquí es calcular esos dos números.
xs = [1, 2, 3, 4, 5]
ys = [2.1, 4.0, 6.2, 7.9, 10.1]

n = len(xs)
media_x = sum(xs) / n
media_y = sum(ys) / n

pendiente = sum((x - media_x) * (y - media_y) for x, y in zip(xs, ys))
pendiente /= sum((x - media_x) ** 2 for x in xs)
origen = media_y - pendiente * media_x

print(origen, pendiente)  # ≈ 0.09 1.99

def predecir(x):
    return pendiente * x + origen

print(predecir(6))        # ≈ 12.03

Un modelo basado en ejemplos: vecinos más cercanos

En los vecinos más cercanos (k-NN) el «modelo» son los propios ejemplos guardados: para clasificar un punto nuevo se buscan los k ejemplos más próximos y se vota su clase mayoritaria. 

import math

# El "modelo" son los ejemplos conocidos.
puntos = [
    {"x": 1, "y": 1, "clase": "A"},
    {"x": 2, "y": 1, "clase": "A"},
    {"x": 1, "y": 2, "clase": "A"},
    {"x": 6, "y": 6, "clase": "B"},
    {"x": 7, "y": 6, "clase": "B"},
    {"x": 6, "y": 7, "clase": "B"},
    {"x": 7, "y": 7, "clase": "B"},
]

def distancia(a, b):
    return math.sqrt((a["x"] - b["x"]) ** 2 + (a["y"] - b["y"]) ** 2)

def clasificar(punto, ejemplos, k=3):
    # Busca los k ejemplos más cercanos y vota su clase mayoritaria.
    ordenados = sorted(ejemplos, key=lambda e: distancia(e, punto))
    votos = [e["clase"] for e in ordenados[:k]]
    return max(set(votos), key=votos.count)

nuevo = {"x": 2, "y": 2, "clase": "?"}
print(clasificar(nuevo, puntos))  # A

Evaluar con datos no vistos

La evaluación mide cómo se comporta el modelo con ejemplos reservados que no participaron en el entrenamiento. Aquí el «entrenamiento» son los puntos guardados. 

# Reserva ejemplos para evaluar: el modelo no debe haberlos "visto".
entrenamiento = puntos[:5]
evaluacion = puntos[5:]

correctos = 0
for ejemplo in evaluacion:
    if clasificar(ejemplo, entrenamiento) == ejemplo["clase"]:
        correctos += 1

print("Acierto:", correctos / len(evaluacion))

Con muy pocos ejemplos, el resultado de la evaluación es poco fiable. En la práctica se usan cientos o miles de ejemplos y se repite la evaluación para obtener medidas estables.

Métricas de evaluación

La elección de la métrica depende de la tarea y de lo que cuesta equivocarse. Para clasificación se usan el acierto (accuracy), la precisión, la exhaustividad (recall) y su combinación F1; para regresión, errores como el absoluto medio o el cuadrático medio.

Métrica Qué mide Precaución
acierto Proporción de predicciones correctas sobre el total. Engañosa con clases desbalanceadas: acertar siempre la clase mayoritaria puede dar un valor alto.
precisión De las veces que el modelo predijo una clase, cuántas acertó. No dice nada de los casos positivos que el modelo dejó pasar.
exhaustividad De los casos reales de una clase, cuántos detectó el modelo. Puede subir a costa de generar más falsos positivos.
F1 Media armónica entre precisión y exhaustividad. Resume dos aspectos, pero oculta cuál de los dos falla.
error cuadrático medio Error medio de una predicción numérica, penalizando más los errores grandes. Sus unidades están al cuadrado; para interpretar, conviene también el error absoluto medio.

Para entender estos valores conviene revisar la matriz de confusión, que desglosa aciertos y errores por clase, y analizar ejemplos concretos en los que el modelo falla.

Buenas prácticas

  • Empezar por la pregunta: definir la tarea, el resultado esperado y el coste de los errores antes de elegir el modelo.
  • Conocer los datos antes de entrenarlos: revisar rangos, valores ausentes y errores de etiquetado.
  • Separar siempre un conjunto de evaluación y no tocarlo hasta la medición final.
  • Elegir métricas acordes al problema y al desbalance de clases.
  • Comparar contra una línea base sencilla antes de usar modelos complejos.
  • Registrar las versiones de datos, hiperparámetros y resultados para poder reproducir el entrenamiento.
  • Revisar los errores del modelo y a quiénes afectan, no solo la métrica global.
  • Reevaluar el modelo cuando cambien los datos o el contexto de uso.

Errores comunes

Error Por qué es un problema Qué hacer
Evaluar con los datos de entrenamiento El modelo puede haberlos memorizado; la medida no refleja la generalización. Reservar ejemplos que el entrenamiento no use.
Ajustar hiperparámetros con el conjunto de prueba El conjunto de prueba deja de ser una medición imparcial. Usar un tercer conjunto de validación o validación cruzada.
Confiar solo en el acierto con clases desbalanceadas Un modelo trivial puede parecer bueno sin detectar la clase minoritaria. Complementar con precisión, exhaustividad y matriz de confusión.
Buscar siempre el modelo más complejo Aumenta el riesgo de sobreajuste y el coste de mantenimiento. Comparar contra una línea base simple y justificar la complejidad extra.
Dejar que información del futuro entre al entrenamiento La evaluación da resultados irreales que no se mantendrán en uso. Revisar qué información está disponible en el momento de la predicción.
Ignorar el desplazamiento de los datos Los datos del mundo real cambian y el modelo queda desactualizado. Supervisar el rendimiento y reentrenar cuando sea necesario.

Referencia rápida

Término Significado
característica Propiedad medible de un ejemplo que sirve de entrada al modelo.
etiqueta Respuesta esperada de un ejemplo en aprendizaje supervisado.
parámetros Valores internos del modelo que ajusta el entrenamiento.
hiperparámetros Valores que se configuran antes de entrenar y no aprende el modelo.
función de pérdida Medida del error que el entrenamiento intenta minimizar.
sobreajuste El modelo memoriza el entrenamiento y rinde peor con datos nuevos.
subajuste El modelo es demasiado simple y ni siquiera describe los datos de entrenamiento.
conjunto de prueba Ejemplos reservados para medir el modelo sin interferir en su ajuste.
fuga de datos Información no disponible en el momento de predecir que contamina el entrenamiento o la evaluación.
