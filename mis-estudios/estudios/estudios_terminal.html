Comandos y terminal

Terminal y línea de comandos

La terminal es una interfaz de texto para controlar el sistema: moverte por carpetas, gestionar archivos, ejecutar programas y combinarlos. Los ejemplos usan Bash, el intérprete más común en Linux y macOS.

¿Qué es una terminal?

La terminal es el programa que muestra texto; el shell es el intérprete que lee tus comandos y los ejecuta. Cada comando tiene la forma programa opciones argumentos. 

echo "Hola, mundo"        # programa: echo, sin opciones, un argumento
  ls -la /home              # opciones -la, argumento /home
  man ls                    # manual de un comando (se sale con "q")

Rutas: . es la carpeta actual, .. la superior, ~ tu carpeta personal y / la raíz del sistema.

Navegación

pwd                 # dónde estoy (print working directory)
  ls                  # qué hay aquí
  ls -la              # listar todo, incluidos ocultos, con detalles
  cd proyectos        # entrar en una carpeta
  cd ..               # subir un nivel
  cd ~                # ir a mi carpeta personal
  cd -                # volver a la carpeta anterior

El tabulador autocompleta nombres y la flecha arriba recupera el comando anterior. Son las dos teclas que más tiempo te ahorrarán.

Archivos y carpetas

mkdir nueva-carpeta        # crear carpeta (-p crea también los padres)
  touch notas.txt            # crear un archivo vacío
  cp origen destino          # copiar (-r para carpetas)
  mv archivo.txt docs/       # mover; también sirve para renombrar
  rm archivo.txt             # borrar (-r carpetas, -i pide confirmación)
  cat archivo.txt            # mostrar su contenido
  less archivo.txt           # verlo por páginas (salir con "q")
  head -n 5 archivo.txt      # primeras 5 líneas
  tail -f log.txt            # últimas líneas, en vivo, mientras crece
  find . -name "*.js"        # buscar por nombre a partir de la carpeta actual

rm no tiene papelera. Un rm -rf mal escrito borra de forma permanente. Comprueba siempre la ruta con pwd y ls antes.

Permisos

Cada archivo tiene permisos para el propietario, el grupo y el resto. Se pueden leer, escribir y ejecutar (r, w, x). 

ls -l script.sh
  # -rwxr-xr-- 1 ana dev 512 ... script.sh
  #  |||| ||| |||-- resto: puede leer
  #  |||| |||-- grupo: leer y ejecutar
  #  ||||-- propietario: leer, escribir y ejecutar

  chmod +x script.sh          # añadir permiso de ejecución
  chmod 644 config.txt        # propietario rw; grupo y resto, solo lectura
  chown ana:dev archivo.txt   # cambiar propietario y grupo (necesita permisos)
  sudo comando                # ejecutar como administrador (úsalo con cuidado)

El código 644 es la suma de los valores r=4, w=2, x=1 para los tres grupos. Es el patrón habitual en archivos normales; 755 se usa para programas y carpetas.

Procesos

ps aux               # listar todos los procesos en ejecución
  top                  # monitor interactivo (salir con "q")
  kill 1234            # pedir que termine el proceso con PID 1234
  kill -9 1234         # forzarlo (último recurso)
  comando &            # lanzar en segundo plano
  jobs                 # ver los trabajos en segundo plano de esta terminal
  fg                   # traer de vuelta el último trabajo en segundo plano
  Ctrl+C               # interrumpir el proceso en primer plano
  Ctrl+Z               # suspenderlo y devolver el control

Tuberías y redirección

La filosofía de Unix: programas pequeños que hacen una cosa bien y se combinan. La tubería | conecta la salida de uno con la entrada del siguiente. 

# Contar cuántos archivos .js hay en el proyecto
  find . -name "*.js" | wc -l

  # Buscar un proceso concreto
  ps aux | grep node

  # Guardar la salida en un archivo (> sobrescribe, >> añade)
  ls -la > listado.txt
  echo "nueva línea" >> listado.txt

  # Descartar errores enviándolos a /dev/null
  comando 2> /dev/null

grep filtra líneas por un patrón, wc cuenta líneas o palabras y sort / uniq ordenan y eliminan duplicados. Encadenados hacen análisis de texto muy potente.
