CSS

CSS (Cascading Style Sheets) es el lenguaje que controla la presentación del HTML: colores, tipografía, espaciado y disposición. Separa el contenido de su aspecto visual.

¿Qué es y cómo se aplica?

Una hoja de estilos es una lista de reglas. Cada regla tiene un selector (a qué elementos afecta) y un bloque de declaraciones (propiedad: valor). 

/* Selector: p. Declaraciones: color y max-width */
  p {
    color: #333333;
    max-width: 40rem;
  }

Se puede aplicar de tres formas, preferidas en este orden:

  1. Archivo externo: <link rel="stylesheet" href="css/tema.css">.
  2. Bloque <style> en el <head>, para estilos puntuales de una página.
  3. Atributo style="": evítalo salvo para pruebas.

La palabra «en cascada» significa que, ante reglas en conflicto, gana la de mayor especificidad y, si empatan, la que aparece más abajo.

Selectores y especificidad

p            { } /* etiqueta */
  .tarjeta     { } /* clase (las más usadas) */
  #principal   { } /* id (poco recomendado para estilos) */
  nav a        { } /* descendiente */
  ul > li      { } /* hijo directo */
  input[type="email"] { } /* por atributo */
  a:hover      { } /* pseudo-clase: estado */
  p::first-line { } /* pseudo-elemento: parte del contenido */

La especificidad se calcula por «peso»: los estilos en línea pesan más que los id, los id más que las clases y atributos, y las clases más que las etiquetas. Ante dudas, usa clases y evita !important. 

/* Variables reutilizables y herencia */
  :root {
    --color-texto: #1b1f24;
  }

  .aviso {
    color: var(--color-texto);
    border-left: 3px solid orange;
  }

El modelo de caja

Todo elemento es una caja formada por el contenido, el padding (relleno interno), el border (borde) y el margin (espacio exterior). 

/* Sin esto, el padding y el borde SUMAN al ancho declarado. */
  *,
  *::before,
  *::after {
    box-sizing: border-box;
  }

  .caja {
    width: 300px;
    padding: 1rem;   /* espacio dentro */
    border: 1px solid #ccc;
    margin: 1rem;    /* espacio fuera */
  }
  • Con box-sizing: border-box, width incluye padding y borde: mucho más predecible.
  • Los márgenes verticales de elementos adyacentes pueden solaparse (margin collapsing).
  • Las unidades relativas (rem, %, em) se adaptan mejor que los píxeles fijos.

Flexbox

Flexbox distribuye elementos en una dimensión (fila o columna). Se activa con display: flex en el contenedor; los hijos pasan a ser elementos flexibles. 

.barra {
    display: flex;
    justify-content: space-between; /* eje principal: horizontal por defecto */
    align-items: center;            /* eje transversal: vertical por defecto */
    gap: 1rem;                      /* separación entre hijos, sin márgenes */
    flex-wrap: wrap;                /* permite pasar a la línea siguiente */
  }

  .barra__marca {
    flex: 1 1 auto; /* grow shrink basis: puede crecer y encogerse */
  }
  • justify-content reparte el espacio en el eje principal.
  • align-items alinea en el eje transversal.
  • flex-direction: column cambia el eje principal a vertical.
  • Para cuadrículas de filas y columnas a la vez, usa Grid.

Grid

Grid organiza los hijos en filas y columnas al mismo tiempo. Es ideal para rejillas de tarjetas y diseños de página completos. 

.rejilla {
    display: grid;
    /* Columnas que se adaptan solas al ancho disponible */
    grid-template-columns: repeat(auto-fill, minmax(16rem, 1fr));
    gap: 1rem;
  }

  .destacado {
    /* Ocupa dos columnas de la rejilla */
    grid-column: span 2;
  }

El 1fr («una fracción») reparte el espacio libre entre columnas. Es la forma más directa de hacer diseños fluidos sin media queries.

Buenas prácticas

  • Separa la presentación en archivos externos y enlázalos desde el HTML.
  • Concentra colores, tipografías y espaciados en variables (custom properties) para cambiarlos en un solo sitio.
  • Usa clases con nombres que describan el significado (.nota), no la apariencia (.caja-amarilla).
  • Prefiere Flexbox/Grid a float y posicionamiento absoluto para maquetar.
  • Diseña primero para móvil y amplía con @media (min-width: …).

Errores comunes

  • Olvidar box-sizing: border-box y llevarse sorpresas con los anchos.
  • Abusar de !important para «arreglar» conflictos: es señal de mala estructura de selectores.
  • Estilar por id, lo que dispara la especificidad y dificulta la reutilización.
  • Usar height: 100% cuando el padre no tiene altura definida: no hace nada.
  • Mezclar unidades sin criterio (px, em, %) y perder escalabilidad.

Si un estilo «no se aplica», revisa en las herramientas del navegador si otro selector con mayor especificidad lo está sobrescribiendo (aparece tachado).

Referencia rápida

Propiedad Qué hace
display Tipo de caja: block, inline, flex, grid, none.
color / background-color Color del texto y del fondo.
font-family / font-size Tipografía y tamaño del texto.
margin / padding Espacio exterior e interior.
border / border-radius Borde y esquinas redondeadas.
width / max-width Ancho fijo y ancho máximo (más flexible).
gap Separación entre hijos de flex o grid.
position static, relative, absolute, fixed, sticky.
