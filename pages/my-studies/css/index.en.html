CSS

CSS (Cascading Style Sheets) is the language that controls the presentation of HTML: colours, typography, spacing and layout. It separates content from its visual appearance.

What it is and how it is applied

A stylesheet is a list of rules. Each rule has a selector (which elements it affects) and a declaration block (property: value). 

/* Selector: p. Declarations: color and max-width */
  p {
    color: #333333;
    max-width: 40rem;
  }

It can be applied in three ways, preferred in this order:

  1. External file: <link rel="stylesheet" href="css/tema.css">.
  2. <style> block in the <head>, for page-specific styles.
  3. style="" attribute: avoid it except for tests.

The word «cascading» means that, when rules conflict, the one with higher specificity wins, and if they tie, the one that appears lower down.

Selectors and specificity

p            { } /* tag */
  .tarjeta     { } /* class (the most used) */
  #principal   { } /* id (not recommended for styling) */
  nav a        { } /* descendant */
  ul > li      { } /* direct child */
  input[type="email"] { } /* by attribute */
  a:hover      { } /* pseudo-class: state */
  p::first-line { } /* pseudo-element: part of the content */

Specificity is calculated by «weight»: inline styles weigh more than ids, ids more than classes and attributes, and classes more than tags. When in doubt, use classes and avoid !important. 

/* Reusable variables and inheritance */
  :root {
    --color-texto: #1b1f24;
  }

  .aviso {
    color: var(--color-texto);
    border-left: 3px solid orange;
  }

The box model

Every element is a box made up of the content, the padding (inner spacing), the border and the margin (outer spacing). 

/* Without this, padding and border ADD to the declared width. */
  *,
  *::before,
  *::after {
    box-sizing: border-box;
  }

  .caja {
    width: 300px;
    padding: 1rem;   /* space inside */
    border: 1px solid #ccc;
    margin: 1rem;    /* space outside */
  }
  • With box-sizing: border-box, width includes padding and border: much more predictable.
  • The vertical margins of adjacent elements can collapse (margin collapsing).
  • Relative units (rem, %, em) adapt better than fixed pixels.

Flexbox

Flexbox distributes elements in one dimension (row or column). It is activated with display: flex on the container; the children become flex items. 

.barra {
    display: flex;
    justify-content: space-between; /* main axis: horizontal by default */
    align-items: center;            /* cross axis: vertical by default */
    gap: 1rem;                      /* gap between children, no margins */
    flex-wrap: wrap;                /* allow wrapping to the next line */
  }

  .barra__marca {
    flex: 1 1 auto; /* grow shrink basis: can grow and shrink */
  }
  • justify-content distributes space along the main axis.
  • align-items aligns along the cross axis.
  • flex-direction: column makes the main axis vertical.
  • For grids of rows and columns at once, use Grid.

Grid

Grid organises children into rows and columns at the same time. It is ideal for card grids and full-page layouts. 

.rejilla {
    display: grid;
    /* Columns that adapt on their own to the available width */
    grid-template-columns: repeat(auto-fill, minmax(16rem, 1fr));
    gap: 1rem;
  }

  .destacado {
    /* Occupies two columns of the grid */
    grid-column: span 2;
  }

1fr («one fraction») shares the free space among columns. It is the most direct way to build fluid layouts without media queries.

Best practices

  • Separate presentation into external files and link them from the HTML.
  • Centralise colours, fonts and spacing in variables (custom properties) to change them in one place.
  • Use class names that describe the meaning (.nota), not the appearance (.caja-amarilla).
  • Prefer Flexbox/Grid over float and absolute positioning for layout.
  • Design mobile-first and expand with @media (min-width: …).

Common mistakes

  • Forgetting box-sizing: border-box and being surprised by widths.
  • Overusing !important to «fix» conflicts: it signals poor selector structure.
  • Styling by id, which spikes specificity and hinders reuse.
  • Using height: 100% when the parent has no defined height: it does nothing.
  • Mixing units without criteria (px, em, %) and losing scalability.

If a style «does not apply», check in the browser's dev tools whether another selector with higher specificity is overriding it (it appears struck through).

Quick reference

Property What it does
display Box type: block, inline, flex, grid, none.
color / background-color Text and background colour.
font-family / font-size Typography and text size.
margin / padding Outer and inner spacing.
border / border-radius Border and rounded corners.
width / max-width Fixed width and maximum width (more flexible).
gap Gap between flex or grid children.
position static, relative, absolute, fixed, sticky.
