JavaScript

JavaScript is the programming language that adds behaviour to web pages: it reacts to events, modifies the DOM and communicates with servers. Today it is also used outside the browser.

What it is and where it runs

JavaScript (JS) runs in an engine (V8 in Chrome, SpiderMonkey in Firefox). Inside the browser it has access to APIs such as the DOM and events; outside, in Node.js, it accesses the server's file system and network.

It is included in a page with the <script> tag:

<!-- At the end of the body: the DOM already exists when it runs -->
  <script src="js/app.js"></script>

The defer attribute downloads the script in parallel and runs it once the HTML has been parsed, without blocking the page from being painted.

Variables and types

Declare with const whenever you can and with let if the value will change. Avoid var because of its confusing scope. 

const name = 'Ana';          // string
  let counter = 0;             // number
  const active = true;         // boolean
  const empty = null;          // intentional absence of a value
  let undefinedValue;          // undefined

  // Comparisons: use === (strict), not == (converts types)
  1 == '1';   // true  (avoid it)
  1 === '1';  // false (correct)

  // Template literals with backticks
  console.log(`Hello, ${name}: ${counter + 1} messages`);

The primitive types are string, number, boolean, null, undefined, bigint and symbol. Everything else (objects, arrays, functions) is by reference.

Functions and scope

// Classic declaration
  function sum(a, b) {
    return a + b;
  }

  // Arrow function, shorter (and without its own this)
  const double = (n) => n * 2;

  // Array of objects + array methods
  const tasks = [
    { text: 'Study', done: false },
    { text: 'Review', done: true }
  ];

  const pending = tasks
    .filter((t) => !t.done)   // filter
    .map((t) => t.text);       // transform

  console.log(pending); // ['Study']

A function has access to the variables of its own scope and of the scopes that contain it (closure). Each module or block creates a scope with let and const.

The DOM and events

The DOM is the in-memory representation of the HTML. JS can read it, modify it and react to what the user does. 

const input = document.querySelector('#buscador');
  const list = document.querySelector('.lista-estudios');

  // React to the user typing
  input.addEventListener('input', (event) => {
    const value = event.target.value.toLowerCase();

    list.querySelectorAll('li').forEach((item) => {
      const matches = item.textContent.toLowerCase().includes(value);
      item.hidden = !matches; // change the DOM based on the text
    });
  });

Use querySelector and addEventListener instead of onclick attributes in the HTML: it separates behaviour from content.

Asynchrony

JavaScript is single-threaded, but it does not block: slow operations (network, timers) are delegated and resumed when they finish. 

// async/await: written sequentially, executed asynchronously
  async function getUsers() {
    try {
      const response = await fetch('/api/users');
      if (!response.ok) {
        throw new Error('HTTP error ' + response.status);
      }
      const data = await response.json();
      return data;
    } catch (error) {
      console.error('Could not load users:', error);
    }
  }

await can only be used inside an async function or at the top level of a module. Always wrap it in try/catch to handle failures.

Best practices

  • Use const by default and let only when the value will change.
  • Always compare with === and !==.
  • Avoid global variables: wrap the code in functions or modules.
  • Separate DOM logic from data logic.
  • Handle errors explicitly instead of silencing them.
  • Run the code after the DOM has loaded (defer or DOMContentLoaded).

Common mistakes

  • Using == and being surprised by type conversions.
  • Confusing null with undefined when checking values.
  • Modifying an array while iterating over it.
  • Thinking an async function blocks: it always returns a promise.
  • Forgetting preventDefault() on a form and reloading the page unintentionally.
  • Unexpected mutations from sharing references between objects.
