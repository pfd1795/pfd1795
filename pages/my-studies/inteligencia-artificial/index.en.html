Fundamentals of computing

Artificial intelligence

Artificial intelligence (AI) brings together methods that let computer systems perform tasks that usually require capabilities associated with human intelligence. In this article you will learn its fundamental concepts, how a model learns and which limits are worth keeping in mind when using it.

In 5 points

  • AI is a broad field; machine learning is one of its areas.
  • A model learns patterns from data and uses them to produce results.
  • Training a model and using it to infer are distinct stages.
  • Data quality and evaluation influence the usefulness of the system.
  • AI outputs can be inaccurate, biased or unsuitable for the context.

What is artificial intelligence?

Artificial intelligence is the area of computing that studies and builds systems able to perform tasks such as classifying information, recognising patterns, generating content, recommending options or planning actions. There is no single AI technique: the field includes rule-based methods, search, optimisation and learning from data.

An AI system does not necessarily think or understand like a person. In many cases it computes an output from an input and from patterns that were defined manually or learned during training.

Key idea: that a system produces a convincing answer does not, by itself, prove that the answer is correct or that the system understands the subject.

Key concepts

  • Machine learning: set of methods that let a system adjust a model using data, instead of specifying all the rules manually.
  • Supervised learning: training with examples that include inputs and expected answers, such as images labelled by category.
  • Unsupervised learning: searching for structures or groups in data without labels provided in advance.
  • Reinforcement learning: learning through interactions and reward or penalty signals.
  • Model: mathematical representation adjusted to produce results from inputs.
  • Training: process of adjusting the model's parameters with data.
  • Inference: using a trained model to produce a prediction or answer.
  • Neural network: family of models made of connected units that transform data through layers of operations.
  • Deep learning: area of machine learning that uses neural networks with multiple layers.
  • Training data: examples used to adjust the model; their coverage and quality affect what the model can learn.

Generative AI is a category of systems that produce content — for example text, images or audio — from learned patterns. Its output can be useful, but it must be checked against the intended use.

How an AI system works

In a typical machine-learning system, data is prepared and used to adjust a model. Then the model is evaluated with examples that were not used for training. If its performance is adequate for the task, it can be used to infer results on new inputs.

  1. Define the task: specify what input the system receives and what result is expected.
  2. Prepare the data: review, organise and, when appropriate, label the examples.
  3. Train: adjust the model so it finds useful patterns in the data.
  4. Evaluate: measure its behaviour on separate data and analyse its errors.
  5. Use and monitor: apply the model in a defined context and review whether it remains appropriate.

A good result on the training data does not guarantee that the model will work well on new examples. It is also important to check whether the evaluation data represents the real context of use.

Illustrative examples

Classification with simple rules

This example does not train a model: it uses a rule written by a person to classify a numeric signal. It serves to contrast a rule-based solution with one that learns patterns from data. 

def classify_temperature(celsius):
    if celsius < 10:
        return "cold"
    if celsius < 25:
        return "mild"
    return "warm"

print(classify_temperature(18))  # mild

Separating data to evaluate a model

The following snippet shows the idea of separating examples before evaluating. It is illustrative: it does not implement training or depend on a machine-learning library. 

data = [
    {"input": "example 1", "label": "A"},
    {"input": "example 2", "label": "B"},
    {"input": "example 3", "label": "A"},
    {"input": "example 4", "label": "B"},
]

# In a real project, the split is usually done reproducibly
# and taking into account the size and distribution of the data.
training_data = data[:3]
evaluation_data = data[3:]

print("Training:", len(training_data))
print("Evaluation:", len(evaluation_data))

These examples use basic Python to explain ideas. They are not a production-ready AI model and do not measure the quality of a prediction.

Applications and limits

AI techniques are used in diverse tasks, such as filtering spam, recognising objects in images, recommending content, transcribing speech or helping explore large data sets. The suitability of each method depends on the task, the available data and the impact of errors.

Among its limits are dependence on data, difficulty explaining some decisions, possible bias, variation in output quality and the lack of any guarantee that a generative system provides true information.

In high-impact decisions — for example those related to health, employment, credit or access to services — it is not advisable to treat the model's output as a final decision without appropriate controls, evaluation and supervision.

Best practices

  • Clearly define the task and the conditions in which the system will be used.
  • Check that the data is relevant, sufficiently representative and obtained appropriately.
  • Separate the evaluation data from the data used to train the model.
  • Measure more than one aspect of performance when a single metric can hide important errors.
  • Review incorrect examples and analyse who those errors affect.
  • Protect personal data and limit its use to what is necessary.
  • Disclose when an output was generated or assisted by AI, if the context requires it.
  • Keep human supervision when the impact of an output is significant.
  • Re-evaluate the system if the data, context or objectives change.

Common mistakes

Mistake Why it is a problem What to do
Confusing AI with machine learning Machine learning is a part of the field, not a synonym for all of AI. Identify the concrete technique that performs the task.
Assuming a fluent answer is true The way something is expressed does not guarantee accuracy or understanding. Verify important data against appropriate sources.
Evaluating only on training data It can hide that the model does not generalise to new examples. Use separate data to evaluate and analyse the errors.
Ignoring the quality and origin of the data Problems in the data can be reflected in the predictions. Document, review and protect the data used.
Automating a decision without supervision Errors can have disproportionate consequences. Establish controls suited to the risk of the task.
